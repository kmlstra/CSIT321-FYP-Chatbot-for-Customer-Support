📋 How to Embed

Clients get this embed code from their dashboard:

<!-- CleverCompanion Widget --> <script> window.CleverCompanionConfig = { clientId: 'client_abc123', apiUrl: 'https://api.clevercompanion.com/widget', branding: { company_name: 'ABC Motors Singapore', primary_color: '#FF6B35' } }; </script> <script src="clevercompanion-widget.js"></script> <!-- End Widget -->

🔄 How It Works:

  1. Client copies embed code from dashboard
  2. Pastes it on their website before </body>
  3. Widget loads with their branding
  4. Connects to their specific configuration
  5. All conversations are isolated to their account
